# Шаблон запроса на запуск сессии

Оркестратор копирует этот файл в `tasks/<задача>/TASK.md`, заполняет плейсхолдеры
и запускает сессию скриптом `claude-kit/launch-session.sh <задача>`.

Незаполненных плейсхолдеров `<...>` в готовом `TASK.md` остаться не должно: пустое
место сессия заполнит догадкой, а догадки — это то, ради чего заведён пункт 6 правил.
Часть из них скрипт запуска проверяет и откажется стартовать, но полагаться на это
нельзя — он знает только те, что перечислены в нём явно.
