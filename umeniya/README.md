# Умения агента

То, что агент умеет сверх переписки: слышать голосовые, рисовать картинки,
делать видео. Лежит в ките намеренно — 15.10 выяснилось, что агент на соседней
машине не умел ничего из этого полтора месяца просто потому, что эти скрипты
жили у одного меня и в установку не входили. Новый агент должен получать их
вместе с китом, а не ждать, пока кто-то вспомнит.

## Слышать голосовые

    umeniya/rasshifrovka.sh файл.ogg

Печатает текст. Нужны ffmpeg и whisper.cpp в `/opt/whisper.cpp`; модель
выбирается по свободной памяти — small при 900 МБ и выше, иначе base.

**whisper.cpp собирают на той машине, где он будет работать.** Скопированный
с чужой падает с «Illegal instruction»: сборка берёт инструкции того процессора,
на котором собирали. Для Xeon E5 v2 и прочих без AVX2:

    cmake -B build -DCMAKE_BUILD_TYPE=Release -DGGML_AVX2=OFF -DGGML_FMA=OFF
    cmake --build build -j2 --target whisper-cli

Модели не зависят от процессора, их можно копировать:

    curl -L -o /opt/whisper.cpp/models/ggml-base.bin \
      https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin

## Рисовать картинки

    umeniya/kartinka-gemini.py "промт" --kuda kadr.png
    umeniya/kartinka-gemini.py "промт" --model pro --kuda kadr.png
    umeniya/kartinka-gemini.py "промт" --iskhodnik osnova.png --kuda novoe.png

Ключ Gemini кладётся файлом правами 600 в `~/.config/claude-kit/gemini-key`,
берётся на aistudio.google.com в проекте с включённой оплатой.

Цена кадра на 15.10.2026: flash — 3 ₽, pro — 11 ₽. Flash хватает для схем,
плашек и фонов; pro берут там, где виден почерк: сложная сцена, люди, текст
внутри картинки.

## Видео

Veo 3.1 доступен тем же ключом Gemini: 8 ₽ за секунду быстрым режимом,
34 ₽ обычным. Отдельного скрипта пока нет.

Движение без генерации — наезды, титры, склейки, таймлапс — делается ffmpeg
и не стоит ничего. Для большинства задач этого хватает, и начинать стоит
с него, а не с генерации.
